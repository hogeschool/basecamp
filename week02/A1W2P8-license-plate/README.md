Consider a valid license plate in The Netherlands _(see valid patterns below)_. <br>
Write a program that begins by reading a string of characters from the user. <br>
Then your program should display a message indicating whether the characters are representing a valid license plate.

###### Valid patterns:
- XX-99-99
- 99-99-XX
- 99-XX-99
- XX-99-XX
- XX-XX-99
- 99-XX-XX
- 99-XXX-9
- 9-XXX-99
- XX-999-X
- X-999-XX
- XXX-99-X
- 9-XX-999

###### Input examples:
1. `License: A-149-HH`
2. `License: 149-A-HH`

###### Output examples:
1. `Valid`
2. `Invalid`
