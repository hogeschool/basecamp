## Keuzevak Django

Het keuzevak Django is een goede vervolgstap op Basecamp. Hier heb je Python geleerd, maar wat kan je daar nou eigenlijk mee? In een korte tijd gaan we met behulp van het Django framework een webapplicatie bouwen. Grote platformen zoals Instagram en Spotify gebruiken nog steeds Django. Praktisch en doelgericht ervaren we hoe Python in te zetten is voor dit soort doeleinden.

Het keuzevak vind plaats op donderdagochtend tijdens de keuzevaktijden (onder voorbehoud). Iedere week twee uur op locatie les met een kleine huiswerkopdracht. De beoordeling is aan de hand van een praktische opdracht die je in de loop van de weken opbouwt (in een tweetal). Als je het succesvol afsluit haal je 2 studiepunten.
