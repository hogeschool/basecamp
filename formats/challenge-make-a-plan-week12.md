## Opdracht: Maak een planning en aanpak voor de Text-Based Game

## Doel van de opdracht

Jullie gaan de bestaande game verbeteren door:

Code te refactoren met de nieuwe concepten die je hebt geleerd.

Nieuwe functionaliteiten toe te voegen met geavanceerdere programmeertechnieken.

Over te stappen naar PyGame als jullie daar klaar voor zijn én de docenten daar akkoord op hebben gegeven.

Deze opdracht helpt je om je programmeervaardigheden verder te ontwikkelen en een completere game te maken.

## Stap 1: Reflectie op de code en samenwerking

Beantwoord de volgende vragen om het idee voor jullie game te bedenken:

Als jullie, met de ervaring van de afgelopen weken, terugkijken op de code, hoe vinden jullie dat deze er dan uit ziet? Hoe ziet de structuur eruit? Kan het bv. beter, netter, korter? Beschrijf kort wat je opvalt aan de code en hoe het eventueel anders kan (max. 5 regels).

Hoe kijken jullie terug op de samenwerking in Arch 2? Wat ging er goed en wat niet (denk aan communicatie, afspraken maken, samen aan code werken) en hoe kan je dit verbeteren voor Arch 3. Geef hier een korte beschrijving.

Refactor de code Welke code/onderdelen kunnen gestructureerder en efficiënter geschreven worden? Pas dit toe in de uitwerking van de game.

## Stap 2: Bepaal de aanpak voor de Challenge Week voor Arch 3

Werk een plan uit.

Welke nieuwe onderdelen/features willen jullie in Arch 3 gaan toevoegen aan de game? Maak een lijst van onderdelen/features die jullie willen toevoegen aan de game. Maak een selectie van de features die jullie deze week willen oppakken. Mochten jullie eerder klaar zijn, pak dan een extra feature op.

Welke nieuwe concepten die jullie in Arch 3 hebben geleerd, kunnen jullie in de game gaan toepassen en waarvoor? (Denk aan classes, objects, .json, csv)

Gebruik bijvoorbeeld classes om:

Spelers, vijanden of voorwerpen als objecten te maken

Het spel overzichtelijker en flexibeler te maken

Gebruik bijvoorbeeld data-opslag om:

Highscores op te slaan in een .json of .csv bestand

De voortgang van de speler op te slaan en te laden
