## Doel van deze peerevaluatie

Het invullen van de peerevaluatie heeft als doel om je te helpen om een actief teamlid te zijn/te worden, oog hebben voor elkaars kwaliteiten en ontwikkelpunten en wat dit voor jou kan betekenen. Daarnaast oefen je met het geven en ontvangen van feedback.

**___________________________________________________________________________**

## Deel A Peerevaluatie

Waarin kun jij anderen in je leerteam goed ondersteunen?

Waar kunnen anderen in je leerteam jou mee helpen?

Bepreek je antwoorden op vraag 1 en 2 en vul bovenstaande vragen eventueel nog aan.

## Deel B Code review

Zoek iemand uit een ander leerteam en kies samen een programmeeropdracht uit week 9, 10 of 11 om te reviewen. Bekijk de code van je medestudent en geef antwoord op de onderstaande vragen.

Welke programmeeropdracht van welke student heb je bekeken?

Programmeeropdracht:

Student:

Hebben de variabelen goede namen? (is het een omschrijving van hetgeen erin zit? Welke zou je anders noemen? Zijn er overbodige variabelen? Komt het overeen met hoe jij het hebt gedaan?)

Doet de code wat het moet doen? En is de code duidelijk in wat het doet? In hoeverre komt het overeen met hoe jij het hebt opgelost?

Hoe zien de if/while statements eruit? (denk aan: duidelijk/clean, zijn er overbodige statements?) In hoeverre komt het overeen met hoe jij het hebt opgelost?

Zijn de PEP8 guidelines  voor Python toegepast? Waar gaat dat goed? Waar kan het beter?

Kan de oplossing simpeler? Vergelijk de code van je medestudent met je eigen code van deze opdracht. Wat valt je op?

Wordt eventuele verkeerde input afgevangen?

## Goal of the peer evaluation

The goal of this peer evaluation is to help you be or become an active team member, to recognise the qualities and points for development in others and what this could mean for you. You will also practise giving and receiving feedback.

**__________________________________________________________________________________**

## Part A Peer evaluation

Discuss your answers to question 1 and 2 with your team members and describe the answers here.

How or with what knowledge/skill can you help/support other team members?

With what could you use help/support from other team members?

## Part B Code review

Find a student from a different learning team and decide together which programming assignment from week 9, 10 or 11 you are going to review. Look at the code of your fellow student and answer the following questions:

Which programming assignment did of which student did you review?

Programming assignment:

Student:

Do the variables have correct namen? (is it a description of what it contains? Which one(s) wwould you name differently? Are there obsolete variables? How does this code compare to your code?)

Does the code do what it’s supposed to do? And is the code clear in what it does?Doet de code wat het moet doen? En is de code duidelijk in wat het doet? How does this compare to how you solved it?

How do the if/while statements look? (think about: are they clear and clean, are there obsolete statements?) How does this compare to how you solved it?

Are the PEP8 guidelines for Python applied? Where does this go well? Where can it be improved?

Is there a simpeler solution possible? Compare your code with that of your fellow student. What differences and similarities do you see?

How is a wrong input handled? (if applicable to the assignment you chose)
