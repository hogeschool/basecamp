## Part B Code review

- Find a student from a different learning team and decide together which programming assignment from week 3, 5 or 6 you are going to review. Look at the code of your fellow student en answer the following questions:
- Which programming assignment did of which student did you review?

Programming assignment:

Student:

- Do the variables have correct namen? (is it a description of what it contains? Which one(s) would you name differently? Are there obsolete variables? How does this code compare to your code?)
- Does the code do what it’s supposed to do? And is the code clear in what it does?Doet de code wat het moet doen? En is de code duidelijk in wat het doet? How does this compare to how you solved it?
- How do the if/while statements look? (think about: are they clear and clean, are there obsolete statements?) How does this compare to how you solved it?
- Are the PEP8 guidelines for Python applied? Where does this go well? Where can it be improved?
- Is there a simpeler solution possible? Compare your code with that of your fellow student. What differences and similarities do you see?
- How is a wrong input handled? (if applicable to the assignment you chose)
- Write a short summary of your findings in Part B question 3 to 8. What goes well? What can be improved? What differences and similarities do you notice when you compare your code with the code of your fellow student?
