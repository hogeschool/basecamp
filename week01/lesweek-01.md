## Doelen van deze week

Uit het lesplan van de opleiding:

- Je begrijpt de basistechnieken van studeren: boek, steps/problems/assignments, code analysis, werkactiviteiten.
- Je kent je docenten, klasgenoten en leerteam.
- Je neemt deel aan en communiceert binnen je leerteam.
- Je kunt een programma maken waarin een gebruiker eenvoudige invoer geeft, en het programma berekent en print het resultaat.

### Programmeerdoelen per step

Uit [`week 1 voorbereiding.md`](./week%201%20voorbereiding.md). Na deze week kun je:

**Step-01: What is a Program?**

- :
- understand the concept of (computer and non-computer) programs.
- experience your first taste of Python without knowing all the details.

**Step-02: Everything starts with Data**

- :
- understand values, variables, primitive data types (int, str, float, boolean).
- understand the concept of mutability (some data types are mutable and some are not).
- implement Python programs containing variables, assigning values, print.
- interpret and implement basic operations of strings: concatenation (combining), duplicating, scanning and slicing.

**Step-03: How to Calculate?**

- :
- understand the main arithmetic operations in Python.
- implement arithmetic expressions in Python.
- convert one primitive data type to another using functions: int(), float(), str(), bool().
- implement Python programs containing: input from the user, type conversion, calculation, printing.

<summary>Leeruitkomsten van Arch 1 (bijlage C van de cursushandleiding)</summary>

- Introductie Hogeschool Rotterdam en Basecamp

**Na deze arch:**

- je maakt kennis met de HR, docenten, studenten en de hulpmiddelen die worden gebruikt

**Programmeerelementen in deze arch**

- primitieve datatypes: character, string, integer, float, boolean
- numerieke basisoperaties: `+ - * / %`
- eenvoudige invoer van de gebruiker en printformats
- booleaanse expressies en `if`/`else`
- stringbewerkingen: `len`, `split`, `join`, `replace`, slicing
- basis van functies: definiëren, aanroepen, `return`, argumenten

**Aan het eind van deze arch kun je:**

- het gedrag van een Python-programma lezen, begrijpen en analyseren met de elementen uit Arch 1
- oplossingen implementeren voor een gegeven probleemstelling met die elementen
- Python-programma's implementeren in de Python Shell en een IDE
- Python-programma's uitvoeren met een terminal en een IDE
