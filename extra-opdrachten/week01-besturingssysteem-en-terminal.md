## Supporting Topic Operating systems

Perform a free (re-)search and explore answers for the following questions:

What is an Operating System and why do we need it?

Consider your own computer and OS (Operating System). How do you interact with the OS: Graphical User Interface (GUI) or commands?

Perform a free (re-)search and carry on the following tasks:

Open a terminal / a command prompt. What is the current folder?

How can you make a list of the contents of the current folder?

Using the command line, create a folder and name it workspace.

Use command prompts and change your current folder such that you are in the folder workspace.

Create a folder basecamp and within basecamp create week01.

You have used an online editor to implement your solutions for the given problems of this week. Save one of the solutions within ../basecamp/week01/. Name the file properly. Make sure that the extension of the file is .py.

Is it possible to execute the downloaded Python program using command line? Try it. Note: You may receive an error because Python is not installed on your machine. In this case, you can try this next week.

Use the command line to create an empty Python file with a proper name.

Use the command line to create another folder named week02 within ./basecamp/. Copy (using the command line) your empty Python file within week02.

Within the folder of week01 use the command line and create a file named summary.txt. Open the file (using commands), write down a summary of commands you have learned and used so far and save the file.
