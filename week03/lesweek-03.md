## Doelen van deze week

Uit het lesplan van de opleiding:

- Je kunt een programma maken met eenvoudige interactie: de gebruiker voert herhaaldelijk invoer in, het programma berekent en print de resultaten.
- Je begint met de zelfevaluatie: waar sta ik nu?
- Je gaat verder met Learn to Learn en Student Success.

### Programmeerdoelen per step

Uit [`week 3 voorbereiding.md`](./week%203%20voorbereiding.md). Na deze week kun je:

**Step-01: Strings**

- :
- interpret and implement Python programs using string operations and functions: *, +, len(), split(), join(), replace(), subsrtings, slicing, f-strings.

**Step-02: Looping with *while***

- :
- interpret and implement Python programs using while loops.

**Step-03: Looping with *for ... in***

- :
- interpret and implement Python programs using for loops.

## Waar deze week naartoe werkt — Arch 1

<details>
<summary>Leeruitkomsten van Arch 1 (bijlage C van de cursushandleiding)</summary>

**Professionele vaardigheden die aan bod komen**

- Introductie Hogeschool Rotterdam en Basecamp
- Leerstrategieën, mindset en motivatie
- Start onderzoekende vaardigheden
- Start problem solving
- Start zelfevaluatie
- Eerste feedback
- Maak een dossier

**Na deze arch:**

- je maakt kennis met de HR, docenten, studenten en de hulpmiddelen die worden gebruikt
- je maakt kennis met verschillende leerstrategieën
- je is zich bewust van een aantal onderzoeksvaardigheden
- je zet de eerste stappen in problem solving
- je weet hoe een dossier op te bouwen en maakt er een begin mee

**Programmeerelementen in deze arch**

- primitieve datatypes: character, string, integer, float, boolean
- numerieke basisoperaties: `+ - * / %`
- eenvoudige invoer van de gebruiker en printformats
- booleaanse expressies en `if`/`else`
- stringbewerkingen: `len`, `split`, `join`, `replace`, slicing
- basis van functies: definiëren, aanroepen, `return`, argumenten

**Aan het eind van deze arch kun je:**

- het gedrag van een Python-programma lezen, begrijpen en analyseren met de elementen uit Arch 1
- oplossingen implementeren voor een gegeven probleemstelling met die elementen
- Python-programma's implementeren in de Python Shell en een IDE
- Python-programma's uitvoeren met een terminal en een IDE

</details>
