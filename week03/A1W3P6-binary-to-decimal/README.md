Write a program that converts a binary number to a decimal number. <br>
Your program should begin by reading the binary number from the user as a string. <br>
Then, it should compute the equivalent decimal number by processing each digit in the binary number. <br>
Finally, your program should display the equivalent decimal number with an appropriate message.

###### Criteria:
- Binary is base 2.
- Decimal is base 10.

###### Input example:
`Binary: 1010`

###### Output example:
`10`
